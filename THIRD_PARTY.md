# Third-party code

The PTv3 backbone is adapted from Pointcept and is covered by the MIT license in `licenses/Pointcept.txt`.

The bundled pointnet2 extension comes from Pointnet2_PyTorch and is covered by the Unlicense text in `licenses/Pointnet2.txt`.

PyTorch3D is an external dependency and is not copied into this repository. The setup command pins the commit used during verification.

The Chamfer CUDA extension was already present in the research workspace. Its upstream license was not preserved there. Confirm its origin and redistribution terms before making this repository public.
